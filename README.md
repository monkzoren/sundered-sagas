# BASTION — Community Server downloads

Download the self-host **Bastion Server** binary from the
[**latest release**](https://github.com/monkzoren/bastion-server-releases/releases/latest):

- **Windows x64** — `bastion-server-windows-x64.exe`
- **Linux x64** — `bastion-server-linux-x64`

Run it: a config panel opens in your browser, and on first launch it fetches the
game engine once. No Docker, no Node. Then share a `ws://your-ip:3000` address
with players, or join your own from the game via **🌐 Play Online → Custom address**.

> This repo only hosts the prebuilt binaries. Releases are published
> automatically by the game's build pipeline.
